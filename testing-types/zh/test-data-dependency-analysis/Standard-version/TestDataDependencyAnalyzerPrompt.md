## 分析方法

- 绘制数据依赖图；识别前置数据、循环依赖和隐式共享；给出创建、复用、隔离及销毁顺序。
- 区分已知事实、证据支持的推断、建议和待确认项。
- 为每项结论给出依据或验证方法，不能把计划描述成执行结果。

- 专项聚焦：针对「测试数据依赖分析」单独识别核心对象、特有失效模式、判定规则和证据；不得以同领域通用检查替代。
