# Browser Compatibility Analysis

Use the [standard version](./Standard-version/BrowserCompatibilityAnalyzerPrompt.md) to analyze browser engines, versions, features, rendering, and interaction differences and produce verifiable scenarios, evidence requirements, and open questions.

Use it during requirement review, test design, and focused risk analysis. It does not replace test execution, vulnerability confirmation, compliance certification, or human approval.
