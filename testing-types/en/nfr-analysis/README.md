# NFR Analysis

Use the [standard version](./Standard-version/NFRAnalyzerPrompt.md) to analyze non-functional quality attributes, constraints, acceptance conditions, and test evidence and produce verifiable scenarios, evidence requirements, and open questions.

Use it during requirement review, test design, and focused risk analysis. It does not replace test execution, vulnerability confirmation, compliance certification, or human approval.
