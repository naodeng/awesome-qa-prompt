# OWASP Risk Analysis

Use the [standard version](./Standard-version/OWASPRiskAnalyzerPrompt.md) to analyze OWASP risk categories, attack surfaces, evidence, and validation directions and produce verifiable scenarios, evidence requirements, and open questions.

Use it during requirement review, test design, and focused risk analysis. It does not replace test execution, vulnerability confirmation, compliance certification, or human approval.
