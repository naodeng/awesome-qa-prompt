# Data Privacy Analysis

Use the [standard version](./Standard-version/DataPrivacyTestAnalyzerPrompt.md) to analyze personal data, collection purpose, access, retention, deletion, and sharing and produce verifiable scenarios, evidence requirements, and open questions.

Use it during requirement review, test design, and focused risk analysis. It does not replace test execution, vulnerability confirmation, compliance certification, or human approval.
