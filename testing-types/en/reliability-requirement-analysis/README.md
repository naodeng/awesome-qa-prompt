# Reliability Requirement Analysis

Use the [standard version](./Standard-version/ReliabilityRequirementAnalyzerPrompt.md) to analyze failure modes, sustained operation, recovery, data integrity, and evidence and produce verifiable scenarios, evidence requirements, and open questions.

Use it during requirement review, test design, and focused risk analysis. It does not replace test execution, vulnerability confirmation, compliance certification, or human approval.
