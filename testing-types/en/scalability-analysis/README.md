# Scalability Analysis

Use the [standard version](./Standard-version/ScalabilityAnalyzerPrompt.md) to analyze load growth, resource scaling, bottlenecks, scaling behavior, and validation and produce verifiable scenarios, evidence requirements, and open questions.

Use it during requirement review, test design, and focused risk analysis. It does not replace test execution, vulnerability confirmation, compliance certification, or human approval.
