# Availability Requirement Analysis

Use the [standard version](./Standard-version/AvailabilityRequirementAnalyzerPrompt.md) to analyze availability objectives, outages, recovery, dependencies, and user impact and produce verifiable scenarios, evidence requirements, and open questions.

Use it during requirement review, test design, and focused risk analysis. It does not replace test execution, vulnerability confirmation, compliance certification, or human approval.
